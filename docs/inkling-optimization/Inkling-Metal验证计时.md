# Inkling 单槽名录解码的 Metal 计时

同一 SQ-10 权重、K=7、FP8 KV、16K 单槽、chunk 512、贪心生成。每个验证命令记录编码起点、提交前时刻、Metal GPUStartTime、GPUEndTime 和主机返回时刻。按每条请求首 token 后的整段时间计算解码速度。

基线首轮前三批普通验证命令的 GPU 时间中位数分别为 110.2、121.2、128.2 ms，提交到 GPU 开始的中位数为 0.24、0.28、0.32 ms。首轮第四批与另一次启动有短暂重叠，排除。随后独立重跑完整基线，四批共 43.13 tok/s，三进程物理合计峰值 2,914,145,656 字节。

把第一批的一轮 1,495 个 dispatch 分别放入单独的命令缓冲区，并按函数累计 GPU 时间。Q8 投影 ink_linear_q8row_mv 合计 37.45 ms，三个专家投影 ink_moe_gu_sk23、ink_moe_gu_sk3、ink_moe_dn_sk23 分别为 18.43、18.39、17.95 ms。拆开编码改变了并发和缓存条件，这些时间用于选择候选，不能直接作为原图时间占比。

对 M=8 启用 MPP MoE 后，同一第一批的验证 GPU 中位数为 154.0 ms，解码 9.51 秒，序列一致。对 M=8 的小输出 Q8 投影改用已有 mm8 后，四批得到 48.29 tok/s，全部与普通贪心逐 token 一致，三进程峰值 2,918,372,824 字节。反向对照的基线与候选各批 GPU 中位数范围为 107.6–112.4 和 109.1–111.4 ms。重复候选时，一条命令在提交到 GPU 开始之间花了 24.257 秒，GPU 执行 111.8 ms。重复测量捕获慢尾后提前结束。两种实验修改都保留在隔离目录。

脚本与原始日志见 [metal-latency](/tmp/dageno-modelbench/metal-latency)。

## 专家投影复用实验

首批名录的一轮八位置验证覆盖 48 次层访问。1,484 个被激活的专家分组中，771 组只处理一个位置，328 组处理两个。将门控与上投影改为固定两位置一组后，四批解码达到 48.20 tok/s，整图 GPU 中位耗时 111.07 ms，基线分别为 43.13 tok/s 和 109.45 ms。单独计时同一轮的两个门控与上投影内核，累计时间从 35.91 增至 36.91 ms。另一个候选以位运算替代 S3 查表，四批解码 16.25 tok/s，GPU 中位耗时 113.39 ms。两种候选的四批输出均与贪心参考逐 token 一致。两者保留为实验，服务采用原内核。原始数据在 [expert-reuse](/tmp/dageno-modelbench/expert-reuse)。
